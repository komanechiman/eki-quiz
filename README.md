# えきクイズ（PWA版）

となりの駅から「あいだの駅」を4択で当てる、幼児向けの駅クイズアプリです。
40路線・のべ827駅を収録しています。

- JR新幹線6路線（東北・山形・秋田・上越・北陸・東海道）
- 山手線、京浜東北線・根岸線
- 中央・総武系統、東海道・横須賀系統、宇都宮線・高崎線、常磐系統
- 武蔵野線・京葉線・横浜線・南武線・相模線・八高線・川越線・鶴見線・久留里線・埼京線
- 東京メトロ全9路線

読み上げは端末内蔵の音声合成、効果音は波形合成なので、**音声ファイルは一切含まれていません**。
インストール後はオフラインでも動きます。

## GitHub Pages で公開する手順

Service Worker は **https でないと動きません**（localhost は例外）。
そのため必ずどこかにホスティングする必要があります。以下は GitHub Pages の場合。

### 1. リポジトリを作る

GitHub で新規リポジトリを作成します（名前は `eki-quiz` など）。
Public / Private どちらでも Pages は公開できます。

### 2. ファイルを置く

このフォルダの中身を **リポジトリ直下に** 置きます。
`index.html` がリポジトリのルートに来るようにしてください。

```bash
git init
git add .
git commit -m "駅クイズアプリ 初回"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/eki-quiz.git
git push -u origin main
```

ブラウザ上でドラッグ&ドロップしてアップロードしても構いません。

### 3. Pages を有効にする

リポジトリの **Settings > Pages** を開き、

- Source: `Deploy from a branch`
- Branch: `main` / `/ (root)`

を選んで Save。1〜2分で公開されます。

### 4. URL を開く

```
https://<ユーザー名>.github.io/eki-quiz/
```

Pixel 9a の Chrome でこの URL を開きます。

### 5. インストールする

Chrome のメニュー（右上の︙）から **「アプリをインストール」** または
**「ホーム画面に追加」** を選びます。

これでホーム画面にアイコンが並び、タップするとアドレスバーのない全画面アプリとして起動します。
**ブックマークではなく実体としてインストールされるので、リンクが外れることはありません。**

## Netlify を使う場合（もっと手軽）

1. https://app.netlify.com/drop を開く
2. このフォルダごとドラッグ&ドロップ
3. `https://ランダム名.netlify.app` が即発行される

アカウント登録不要ですが、匿名デプロイは後から管理・更新ができません。
長く使うなら GitHub Pages をおすすめします。

## アプリを更新したいとき

駅を足したり文言を変えたりしたら、**必ず `sw.js` の以下の行を変更してください。**

```js
var CACHE_VERSION = "v1";   →   "v2" に上げる
```

これを忘れると、古いファイルがキャッシュから読まれ続けて更新が反映されません。

バージョンを上げて push すると、次回起動時に画面下部へ
「あたらしい バージョンが あります」というバーが出ます。
「こうしん」を押すと最新版に切り替わります。

## 使い方メモ

| 操作 | 内容 |
|---|---|
| 🔊（右上） | 音声のオン / オフ |
| ⚙️（右上） | 読み上げる声の種類と、話す速さを変更 |
| 🏆（右上） | これまでの得点の履歴を表示 |
| 🔊（問題の下） | 問題をもう一度読み上げる |

1ラウンドは8問です。答えると大きな ◯ / ✕ が出て、間違えたときは正解の駅名と
ふりがなを表示してから次の問題に進みます。

### 音声をもっと自然にする

読み上げは端末が持っている音声を使っています。標準の声が機械的に感じる場合、
Android では **設定 > システム > 言語と入力 > 音声出力 > テキスト読み上げの設定**
から Google 音声サービスの日本語データをダウンロードすると改善します。

iPhone の場合は **設定 > アクセシビリティ > 読み上げコンテンツ > 声 > 日本語**
で「Kyoko（拡張）」を追加してください。

追加した声は ⚙️ ボタンの一覧から選べます。

## 得点履歴の保存について

履歴は端末のブラウザ内に保存されます（直近50回分）。サーバーには何も送信しません。
ブラウザの閲覧データを消去すると履歴も消えます。
シークレットモードで開いた場合はその場限りの保存になります。

- 湘南新宿ラインと上野東京ラインは路線ではなく運転系統のため、主要停車駅を並べたものです。
